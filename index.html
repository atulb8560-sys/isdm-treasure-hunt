How it works

1. Add your name under any team column. 2. Names shuffle and are divided as equally as possible. 3. Registration closes on 4 November 2026 at 11:59 PM IST. 4. After closing, no new entries are accepted and the final allocation stays fixed.

Admin setup — connect the shared registration database

A Supabase project is needed for everyone to see the same registrations. Create a project, run the supplied setup.sql in its SQL Editor, then paste the Project URL and anon/public key below. These are public client settings, not your service-role key.
